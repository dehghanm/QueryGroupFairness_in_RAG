# Group-Query-Fairness

In this repositry, we share the codes related to our experiments on investigating the problem of Group Query Fairness in RAG settings. Group query fairness is concerned with whether a RAG system is systematically more accurate for queries that relate to particular groups within a fairness category, or when the inclusion of the retriever component in RAG results in greater accuracy improvements for particular query groups.

We use the TREC 2022 Fair Ranking Track test collection, which is well-suited for evaluating group-level fairness in RAG systems, to construct three datasets that we use to address our research questions. In this repository, we have shared our datasets along with their queries and ground truth.
